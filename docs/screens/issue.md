# Screen: Issue

**Route:** `/<teams|topic|org|space>/{id}/issues/{issue_id}`

## Purpose

The detail page for a single issue. Shows the issue's title, description, author (unless anonymous), status, continuously visible open age, personal-#1 nomination state, assignee, deadline, progress, scope-specific support scores, and supporter allocations (subject to attribution rules). Management activity is shown separately from creator-confirmed or peer-voted closure.
